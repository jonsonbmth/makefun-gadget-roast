A one-line roast of the gadget I use most, written for make.fun's
[One Line Roast the Gadget You Use](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610)
bounty ($5 in USDC).

> My smart speaker heard 'play jazz' as 'buy a kayak', and now I own a kayak.

## How it works

`main.py` (Python 3, standard library only) writes the single roast line to
`/output/entry.txt` and prints it to stdout. It takes no arguments and is
deterministic: every run produces the same bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
